DCA Harvester Guide

1. Genome & Wildcard Control

• Input a 20-letter text sequence to calculate the specific genome parameters.

• Use * as a wildcard character anywhere in the 20-letter code to search and generate patterns across multiple rule variations continuously. (e.g. ASBSNCDDCSSCCXVCCD*** )

2. RAC (Rules Active Count) Range

• Defines the range of active rules applied out of the total rule set (up to 45 rules).

• Higher RAC values generally produce more intricate, highly complex patterns and a larger diversity of dynamic outputs.

3. Initial Seed & Palette Settings

• Seed: Sets the 4 initial boundary values (e.g., 1122) of the starting seed cell.

• Palette & Color Offset: Choose color palettes and adjust the color offset value to cycle through color mappings dynamically.

4. Caption & Output Customization

• Caption: Custom title or author text rendered at the bottom of generated high-resolution images.

• Preview Time: Sets the division time-step depth for preview rendering (e.g., 10 for 1024x1024 grid).

5. Action Buttons

• Random: Generates a random 20-letter code sequence automatically.

• Harvest: Starts searching and generating patterns matching your code criteria.

• Folder: Connects a local folder to auto-save generated high-resolution images.
