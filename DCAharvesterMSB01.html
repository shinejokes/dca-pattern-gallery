DCA Harvester Guide

1. Genome & Symmetry Control

• Input a 20-letter text code to generate specific pattern rules.

• Use * as a wildcard character anywhere in the 20-letter code to search and generate patterns across multiple variations.

• Select initial symmetry configurations: HV, Horizontal, Vertical, Diagonal, or NoSymmetry.

2. Image Size & Palette

• Select output rendering resolution: 1024x1024 or 2048x2048.

• Choose color palettes to texture and colorize the subdivision faces.

3. Custom Caption

• Set custom title text to be rendered at the bottom of generated texture images along with the initial seed and genome information.

4. Action Buttons

• Random: Generates a random 20-letter code sequence automatically.

• Harvest: Starts generating patterns matching your code criteria.

• Folder: Connects a local directory to auto-save generated high-resolution images.
